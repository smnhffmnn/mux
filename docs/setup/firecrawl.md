# Firecrawl

## Prerequisites

- A Firecrawl account and API key.

### Getting an API key

1. Sign up at [firecrawl.dev](https://firecrawl.dev/).
2. Go to **Dashboard → API Keys**.
3. Create a new key and copy it.

## Fields

| Field | Description |
|------|-------------|
| API URL | URL of the Firecrawl API. Default: `https://api.firecrawl.dev`. Only change for self-hosted instances. |
| API Key | Your Firecrawl API key (format: `fc-...`). Stored in the Keychain. |

## After creating

Click **Test** to verify the connection. mux probes the API with a test request.

## Notes

- Firecrawl offers web scraping, crawling, and search. Available tools depend on your plan.
- For self-hosted Firecrawl instances, adjust the API URL accordingly.
