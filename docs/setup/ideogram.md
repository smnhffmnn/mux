# Ideogram

## Prerequisites

- An Ideogram account with API access.
- An API key.

### Getting an API key

1. Open [ideogram.ai](https://ideogram.ai/).
2. Go to the API settings.
3. Create a key and copy it.

## Fields

| Field | Description |
|------|-------------|
| API URL | URL of the Ideogram API. Default: `https://api.ideogram.ai`. |
| API Key | Your API key. Stored in the Keychain. |

## After creating

Click **Test** to verify the connection.

## Notes

- Ideogram offers AI-powered image generation with a strong focus on text rendering within images.
- The API URL typically does not need to be changed.
