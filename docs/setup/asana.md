# Asana

## Prerequisites

- An Asana account.
- A Personal Access Token (PAT).

### Creating a token

1. Open [app.asana.com](https://app.asana.com/).
2. Go to **My Settings → Apps → Developer Apps**.
3. Click **Create New Token**.
4. Copy the token.

## Fields

| Field | Description |
|------|-------------|
| Personal Access Token | Your PAT (format: `0/abc123...`). Stored in the Keychain. |

## After creating

Click **Test** to verify the connection.

## Notes

- The PAT has the same permissions as your Asana user.
- For MCP-based access, use the **Asana MCP** type instead.
