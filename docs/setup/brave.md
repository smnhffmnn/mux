# Brave Search

## Prerequisites

- A Brave Search API account and API key.

### Getting an API key

1. Sign up at [brave.com/search/api](https://brave.com/search/api/).
2. Create a subscription (a free tier is available).
3. Copy your API key from the dashboard.

## Fields

| Field | Description |
|------|-------------|
| API URL | URL of the Brave Search API. Default: `https://api.search.brave.com`. |
| API Key | Your API key (format: `BSA...`). Stored in the Keychain. |

## After creating

Click **Test** to verify the connection.

## Notes

- The free tier is limited to 2,000 requests per month.
- The API URL typically does not need to be changed.
