# mux -- MCP Unified Exchange

Single-binary MCP gateway that provides AI agents unified access to databases (PostgreSQL, ClickHouse, MariaDB), upstream MCP servers (YouTrack, Sentry, etc.), and private networks via WireGuard tunnels. Written in Go with a native Wails v3 desktop app.

## Tech Stack

- **Go 1.25** with `internal/` package layout
- **Wails v3** -- native desktop app (WebView) with Svelte 5 frontend
- **mcp-go** (`github.com/mark3labs/mcp-go`) -- MCP server + client
- **TOML config** (`~/.mux/config.toml`) -- non-sensitive settings
- **OS Keychain** (`go-keyring`) -- passwords, tokens, WireGuard keys
- **WireGuard** (`golang.zx2c4.com/wireguard` + gVisor netstack) -- userspace tunnels

## Key Architecture Patterns

### Dual-Mode (main.go)
```
Stdin piped? -> MCP Stdio Server (no GUI -- e.g. Claude Desktop)
Stdin Terminal? -> application.New() + app.Run()
                  |- MCP HTTP Server as goroutine (Port 7700)
                  |- OAuth Callback Handler (/oauth/callback)
                  +- Wails WebView: Svelte Frontend
```

### Wails v3 Service (app.go)
The `App` struct is registered as a Wails v3 Service. All exported methods become frontend bindings. **app.go has zero Wails imports** -- event emission uses a callback (`emitEvent`) set by main.go.
- **Read**: `GetPageData()`, `GetServerInfo()`, `GetConnectionTypes()`, `GetConnection(name)`
- **Write**: `AddConnection()`, `SaveConnection()`, `DeleteConnection()`, `TestConnection()`, `SetupERP()`, `SyncERP()`, `SelfUpdate()`
- **Auth**: `StartOAuth()`, `GetOAuthStatus()`, `StartDeviceAuth()`, `GetDeviceAuthStatus()`

### Dynamic Connections
Connections are defined in `[[connections]]` TOML arrays. Any number, any type. Each gets tools prefixed with its name.

### Fail-Closed Tunnels
If a connection references a tunnel and that tunnel is down, the connection is **skipped**.

### Config Priority
Environment variables > OS Keychain > TOML file > Defaults

## Build

```bash
make build            # Desktop build (bindings + frontend + Go)
make bindings         # Regenerate Wails v3 TypeScript bindings
make frontend         # Build frontend only (includes bindings)
make dev              # Instructions for dev mode
go test ./...         # Run tests
go build ./...        # Verify compilation
go vet ./...          # Lint
```

## Adding a New Connection Type

1. Create `internal/tools/mydb.go` with struct implementing `Tools() []ToolDef`
2. Constructor takes `(conn config.Connection, dialer Dialer)` -- dialer may be nil
3. Add case to `RegisterConnection()` switch in `internal/tools/tools.go`
4. Add default port in `ApplyConnectionDefaults()` in `internal/config/config.go`
5. Add test handler in `app.go` (`testMyDB()`)
6. Add type entry to `typeRegistry` in `app.go`

## Keychain Key Conventions

| Key Pattern | Content |
|---|---|
| `{connection-name}-password` | DB password |
| `{connection-name}-token` | Bearer token (proxy) |
| `{connection-name}-oauth-token` | OAuth token JSON |
| `{connection-name}-oauth-client-id` | OAuth client ID |
| `{connection-name}-oauth-refresh-token` | OAuth refresh token (microsoft-graph) |
| `tunnel-{tunnel-name}-private-key` | WireGuard private key |
| `tunnel-{tunnel-name}-preshared-key` | WireGuard PSK |
| `erp-token` | ERP provisioning bearer token |
